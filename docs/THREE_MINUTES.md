# 3 分钟快速评审

> 如果你是第一次打开 SmartLive，只想在几分钟内判断这个项目值不值得继续看，直接按这页往下点就够了。

## 1. 先看什么

推荐顺序只有 5 步：

1. 先看项目规模和我到底做了什么
2. 再看真实页面和业务闭环是否完整
3. 再确认页面数量和能力覆盖是否扎实
4. 最后看核心链路和性能数据有没有工程深度

## 3. 你应该重点关注什么

### 3.1 项目是不是完整

先看：

- 是否同时覆盖用户端、商家端、平台管理端
- 是否不只是页面，而是真的有后端服务、链路图和部署说明
- 是否保留了足够多的工程资料，而不只是 README 堆概念

### 3.2 页面是不是够真实

先看：

- 用户端有没有完整的登录、搜索、下单、评价、社交、AI 链路
- 商家端有没有经营总览、店铺商品管理、订单履约、商家助手
- 平台管理端有没有审核中心、评论评价治理、业务用户、积分配置

### 3.3 核心链路是不是够强

建议重点看这几条：

- 秒杀抢购链路
- 订单、支付与退款补偿链路
- Redis 分层缓存链路
- 审核中心责任链与搜索同步链路

### 3.4 数据是不是能自圆其说

建议重点看：

- `16 个业务模块`
- `19 个服务应用`
- `7 万+ Java 代码`
- `200+ Git 提交`
- 秒杀压测、缓存读链和性能页里的量化结果
