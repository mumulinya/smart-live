# 核心链路总览

这页是“核心链路深度解析”的总入口。

如果你是第一次进入这个分区，不建议一上来就随机点某一条链路。更顺的阅读方式是：

1. 先从 **秒杀 / Redis / 订单支付** 这三条链路建立对项目交易闭环的认识
2. 再看 **RabbitMQ / Feed / 审核与搜索**，理解异步解耦和多模块协作
3. 最后看 **热榜 / AI**，把推荐、搜索、向量检索和业务融合串起来

如果你是拿这套链路做项目讲解，建议按下面 4 步展开，不要一上来就从某个实现细节往里钻：

1. 先回到 [系统架构与项目规模](/site-pages/SYSTEM_ARCHITECTURE)，用 1-2 分钟讲清项目边界、服务数量、端侧覆盖和基础设施分工。
2. 再切到 [页面效果图导览](/PAGE_GALLERY) 或 [业务链路视觉走查](/SHOWCASE)，先把用户闭环和页面落点讲出来。
3. 然后在这页只挑 3 条最强链路重点展开，推荐优先讲：`秒杀抢购`、`订单/支付/退款补偿`、`Redis 分层缓存`。
4. 最后回到 [技术选型理由](/site-pages/TECH_SELECTION) 和 [难点踩坑与解决方案](/site-pages/PITFALLS)，把“为什么这么做”和“踩过哪些坑”补齐。
